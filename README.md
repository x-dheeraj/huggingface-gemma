# Hugging Face Gemma

A simple project exploring local LLM inference with
Gemma 3, Hugging Face Transformers, and PyTorch.

## What I learned

- Hugging Face Hub
- Transformers library
- `pipeline()`
- Loading a pretrained model
- Running text generation locally
- Basic LLM inference

## Model

Gemma 3 1B IT

## Run

python3 main.py
